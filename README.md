# ORAVIA — pitch deck

## How to open it

Double-click **index.html**. That's the whole procedure. No installation,
no server, no build step, no terminal.

Keep the three files together in the same folder — `index.html`, `styles.css`
and `app.js`. Moving one without the others will break the deck.

## Presenting

| Key | Does |
|---|---|
| `←` | next slide (the deck is right-to-left, so left is forward) |
| `→` | previous slide |
| `space` | next slide |
| `F` | presentation mode — hides the navigation chrome and goes full screen |
| `Esc` | leave presentation mode |
| `Home` / `End` | first / last slide |

On a phone or tablet, swipe. The dots down the left edge jump to any slide.

Three slides are interactive rather than static, and are worth clicking
during a live pitch: the dental map (slide 8), the time machine (slide 9),
and the voice capture (slide 10).

## Internet connection

The deck loads two web fonts if it can reach the internet. Without a
connection it falls back to system fonts and everything still works — safe
to present offline.

## Before this deck is shown to an investor

Two things in it are deliberately unfinished, and both are flagged inside
the deck itself rather than hidden:

1. The dentist headcount is from 2016. Request the current figure from the
   Conseil National de l'Ordre des Médecins Dentistes de Tunisie.
2. Nothing claims legal compliance. Before the first paying clinic, get a
   written position from Tunisian counsel on Law 2004-63 art. 63 and INPDP
   Délibération 4/2018 — specifically on whether a SaaS vendor may process
   identified dental records, and on data residency.

All patient data in the deck is fictional.
